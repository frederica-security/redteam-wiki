# 快速开始

### 💖 欢迎来到新手村 {#欢迎来到新手村}

> **注意**<br> 在学习红队行动（Red Teaming）和攻防对抗前，我们希望您具备一些网络安全领域的基础知识，包括**渗透测试基础**、**网络协议**（TCP/IP）、以及**操作系统原理**等。我们强烈建议您具备这些基本技能后再开始红队的学习。

这篇教程会引导你大致了解 **Red Team** 行动的目标、方法论和核心流程，并帮助你建立起**面向实战的攻击者思维**。

文档将持续完善，如果您有任何建议或发现不足，欢迎在评论区留言。

---

### 🚨 核心切入：你的宏伟目标是什么？ {#核心切入你的宏伟目标是什么}

**让我们想象一下：** 你是一名黑客，或者更准确的说，红队行动专家，你的任务目标是窃取一家大型科技公司的**核心源代码**，而你现在正坐在自己的电脑前，面对着目标公司的网络。

现在，请思考三个递进的关键问题：

1. **目标选择：** 你要攻击的系统是哪个？你如何知道它的网络地址？你怎样判断哪个入口最容易突破？ 👉 **这引出了 Red Team 的第一步：侦察 (Reconnaissance)**
2. **获取控制：** 假设你找到了一个突破点，成功在目标系统上运行了一小段代码。**然后呢？** 你如何才能在不被发现的情况下，远程地、稳定地、随心所欲地控制这台机器？ 👉 **这引出了 Red Team 的核心：命令与控制 (C2)**
3. **达成任务：** 假设你已经获得了控制权，但你发现核心代码并不在这台机器上。你下一步要做什么？如何从这台机器**横向移动**到下一台，直到拿到核心数据？ 👉 **这引出了 Red Team 的任务：后渗透 (Post-Exploitation) 与目标达成**

**命令与控制（C2）**，是连接**突破**与**任务达成**的关键枢纽。它赋予了你远程操纵目标系统的权力，是红队行动中**真正的神经中枢**。

### 📌 什么是 C2？ {#什么是-c2}

在红队语境中，C2 不仅仅是一个工具，它是一整套**通信架构**和**战术系统**：

- **它的本质：** C2 是一个远程通道，允许你（攻击者）与你已成功植入目标系统中的恶意载荷（我们称之为 **Agent** 或 **Beacon**）进行**隐蔽、稳定、双向的通信**。
- **它的作用：** 无论你在世界的哪个角落，C2 让你能够像操作本地电脑一样，远程指挥目标机器执行任何你想要的命令——从简单的文件列举，到复杂的权限提升、横向移动等后渗透任务。

### 🛡️ C2 的核心挑战：隐蔽对抗 {#️-c2-的核心挑战隐蔽对抗}

对于初学者来说，C2 的难点不在于发送命令，而在于如何**不被发现**。

红队行动的成功，往往取决于 C2 通信的**隐蔽性**。你需要思考：

- **如何伪装？** 你的通信流量如何才能看起来像正常的企业网络流量（例如伪装成浏览器访问网站、DNS查询、或者企业内部聊天）？
- **如何持久？** 即使目标重启了系统，你的控制通道如何才能自动恢复并等待你的命令？
- **如何灵活？** 当一个通信通道被蓝队封锁后，你如何能迅速切换到另一个备用通道？

**C2 环节，将真正把你的实战能力与传统理论知识区分开来。**

### 常见问题 Q&A {#常见问题-qa}

#### Q：Red Team 和 CTF 有什么区别？ {#qred-team-和-ctf-有什么区别}

A：这是很多拥有 CTF 经验的新手普遍存在的困惑。两者最大的区别在于**目标设定**、**环境**和**隐蔽性**要求：

| 特征 | CTF (夺旗赛) | Red Team (红队行动) |
| --- | --- | --- |
| **目标** | 找到一个已知的、预设的 **Flag**。 | 达成一个**业务目标**（如窃取核心数据），路径是**未知**的。 |
| **环境** | 靶机通常有**有限的漏洞**组合。 | 目标是**真实的企业环境**，防御系统**实时运行**。 |
| **隐蔽性** | **不要求**隐蔽，解出即得分。 | **核心要求**是保持隐蔽，避免被蓝队检测、分析和阻断。 |
| **思维** | **验证知识**，找到解题的知识点组合。 | **模拟对手**，从攻击者的视角制定完整的攻击**战略**和**流程**。 |

**简而言之：** CTF 是在“已知有解的题目中找到一个解法”；红队是“在不知道有没有解的真实环境中，规划一条隐蔽的路径，达成业务目标”。

#### Q：什么是 Red Team？ {#q什么是-red-team}

A：「Red Team」中文一般译作**红队**。它是一支专业的网络安全团队，模拟现实中的**高水平攻击者**（APT），使用真实世界的攻击技术、工具和流程，对组织的防御能力（蓝队）进行**对抗性模拟**。红队的目标不是简单地找漏洞，而是**测试组织的整体防御、检测和响应能力**，发现复杂、跨越多个系统和流程的业务高风险缺陷。

#### Q：Red Team 行动流程？ {#qred-team-行动流程}

A：红队行动遵循一个严谨的**生命周期（Kill Chain）**，强调**隐蔽性**和**持续性**。核心流程通常包括：

| 阶段 | 目的/目标 | 关键词 |
| --- | --- | --- |
| **侦察 (Reconnaissance)** | 收集目标信息、识别潜在入口点。 | OSINT, 资产测绘, 邮件/社交工程 |
| **武器化 (Weaponization)** | 结合 Payload 和 Exploit，生成攻击武器。 | C2 Beacon, Stager, Dropper |
| **载荷投递 (Delivery)** | 将武器送到目标手中（如邮件、Web下载）。 | Phishing, 钓鱼邮件, 供应链攻击 |
| **利用 (Exploitation)** | 触发漏洞，获取初始立足点（Initial Access）。 | 0day/Nday, 弱口令, 权限提升 |
| **权限维持 (Persistence)** | 确保在目标上拥有持续、不间断的访问权限。 | 后门, 定时任务, 隐藏账户 |
| **命令与控制 (C2)** | 建立隐蔽通道，远程指挥目标机器执行任务。 | C2 Framework, Domain Fronting |
| **目标达成 (Objectives)** | 完成核心任务（如数据窃取、破坏、横向移动）。 | 横向移动, 域控接管, 核心数据提取 |

#### Q：学习红队有什么要求么？ {#q学习红队有什么要求么}

A：最关键的能力是**信息检索能力**和**快速学习能力**。

说人话就是：**懂得使用搜索引擎高效获取信息，能读懂（甚至复现）技术分析报告，并能快速将新的知识点运用到实战场景中。**

### 从哪开始？ {#从哪开始}

如果你是完全的新手，可以先从以下三个最容易建立**实战思维**的方向入手，找到攻防对抗的“感觉”：

1. **侦察与情报收集 (OSINT/Reconnaissance)：**
    - 这是红队生命周期的**第一步**，也是最重要的一步。
    - 学习如何像攻击者一样，从公开渠道收集目标信息，能让你理解**宏观的攻击思路**，而不是只聚焦于单个漏洞。
2. **网络攻防 WEB：**
    - Web 应用是红队获取初始立足点（Initial Access）最常用的入口之一。
    - 相较于二进制逆向和底层 Pwn，Web 入门门槛相对较低，能让你快速熟悉漏洞的**利用流程**和**反弹 Shell** 的概念。
3. **社会工程学与钓鱼 (Social Engineering & Phishing)：**
    - 正如目录所说，这是你获取**第一台战利品**的常见手段。
    - 学习如何利用信任、诱导目标执行恶意操作（如打开附件、点击链接），是绕过复杂网络防御、直击目标员工的**高效率手段**。这能帮助你理解“人”在防御链条中的重要性。

> **注意：** 入门方向只是为了熟悉红队行动的流程和思维模式，并不决定你最终的技术方向。

### 如何练习 {#如何练习}

> 红队技术学习必须在**授权环境**下进行！靶场是你的最佳练兵场。

- **TryHackMe (THM)**
    - **定位：** 非常适合红队新手和知识系统化学习。采用游戏化（找 Flag）形式，但内容围绕完整的实战流程设计，提供详细的**引导式教学**。
    - **重点：** 拥有大量针对 Windows 和 **Active Directory (AD) 内网渗透**的房间和学习路径。
    - **付费模式：** 免费用户可访问基础房间；付费订阅解锁高级学习路径和所有内网靶机。
- **Hack The Box (HTB) Labs**
    - **定位：** 业界知名的靶场，挑战性强，更接近真实环境。适合具备一定基础后的进阶训练。
    - **重点：** **Pro Labs (专业实验室)** 专为模拟真实企业的复杂、多层级网络设计，是练习**复杂横向移动**、**域信任攻击**和**红队流程**的最佳选择。
    - **付费模式：** 部分靶机免费（需连接 VPN）；Pro Labs 和某些高级功能需要付费订阅。
- **自建实验环境**
    - **定位：** 最自由的练习方式。使用 VMware 或 VirtualBox 自行搭建 **Windows 域控 (DC)**、客户端和攻击机。
    - **优势：** 完全可控，方便测试持久化、C2 框架和各种 AD 错误配置，有助于理解底层原理。
