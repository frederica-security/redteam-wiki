# 攻城略地：横向移动与战果的指数扩增

想象一下，您刚刚在上一关成功洗劫了一个房间，手里攥着几把零星的钥匙。当您推开房间的后门，眼前的景象令人振奋又敬畏：这不再是一个独立的房间，而是一座相互连通、守备森严的**庞大城池（企业内网与云架构）**。

如果在单台机器上的操作是“战术性”的潜伏，那么 **横向移动** 就是一场“战略性”的战役。我们将利用已有的立足点，不断把手里的“小筹码”滚成“大雪球”，直到彻底接管整个数字帝国的控制权。

在开启这场战役之前，我们需要清楚接下来的四大主战场：

| 战役阶段（您的目录） | 目标（内网行动） | 核心目的 |
| --- | --- | --- |
| **扫描和密码喷洒** | **摇晃每一扇门把手** | 闭着眼睛摸黑是不行的，我们要以最低的动静，找出城墙的裂缝和防守最薄弱的偏门。 |
| **Windows AD 域攻防** | **直捣帝国权力中枢** | 掌握了域，就掌握了规则。我们要从边缘小卒一路伪装，直至夺取“皇帝的传国玉玺”。 |
| **堡垒机和网络设备** | **策反敌人的禁卫军** | 绕过最厚的防弹门，或者直接拿下看门人。把防守方最依赖的武器，变成我们的超级跳板。 |
| **云环境渗透** | **远征天空之城** | 战场不再局限于物理机房，我们要跨越新的边界，去接管那些漂浮在云端的数据金库。 |

### 1. 扫描和密码喷洒：从新手用到退役 {#h-1-扫描和密码喷洒从新手用到退役}

攻入内网的第一步，是驱散战争迷雾。但如果您像无头苍蝇一样疯狂扫描，瞬间就会被安全设备（态势感知/SOC）的警报淹没。

- **🕵️‍♂️ 隐蔽扫描（摸清地形）：** 高手从来不强攻。我们要像幽灵一样，探测存活的主机、开放的端口和运行的服务，绘制出这只“数字巨兽”的内部拓扑图。
- **💦 密码喷洒（以巧破力）：** 与其对着一个高价值账户疯狂爆破（这会触发账户锁定警报），不如反其道而行之——拿几个最常见的弱口令（比如 `1QAZ@wsx`），去**轻轻“碰”一下内网里的几千个账号**。

> **红队法则：** 只要基数足够大，总有一个粗心的员工还在用初始密码。这招虽然古老，但在流量设备不敏感的内网里仍然是扩增战果的“起手式”。

### 2. Windows AD：域攻防的那些事 {#h-2-windows-ad域攻防的那些事}

如果企业内网是一个国家，那么 **Active Directory (活动目录，简称AD)** 就是它的中央政府。系统不认人，只认票据和令牌。

- **🎫 信任的连环套：** 域环境的本质是信任。在这个复杂的网状结构中，我们不再需要枯燥地猜测密码明文。我们将学习如何利用黄金票据（Golden Ticket）、白银票据、哈希传递（PtH）等魔法。
- **👑 权力王座（域控）：** 我们的终极目标是**域控制器 (Domain Controller)**。拿下它，您就拿下了整个网络的“户籍室”和“最高法院”。您可以伪造任何人、登录任何机器、访问任何机密。从单机到域控，这就是战果指数级暴涨的巅峰。

### 3. 堡垒机和网络设备：是盾牌也是阿喀琉斯之踵 {#h-3-堡垒机和网络设备是盾牌也是阿喀琉斯之踵}

企业为了防备黑客，斥巨资购买了防火墙、VPN、堡垒机。这些设备就像是城池里的重装禁卫军。

- **🛡️ 盾牌的另一面：** 堡垒机集中管理着所有核心服务器的密码。防守方认为它是最安全的保险箱，但在红队眼里，它就是一个**一站式购物中心**。
- **🗡️ 致命的弱点：** 网络设备通常不安装杀毒软件，一旦它们的漏洞（如常见的 VPN 1Day 漏洞）被撕开，或者堡垒机的权限被我们窃取，这些原本用来抵御攻击的坚盾，瞬间就会变成我们在内网中畅通无阻的“超级VIP通道”。

### 4. 云环境渗透：新的边界和挑战 {#h-4-云环境渗透新的边界和挑战}

随着时代的发展，城墙被推倒了。企业把最核心的数据搬到了 AWS、阿里云、腾讯云等云端。传统的内网渗透手法在这里需要全面升级。

- **☁️ 漂浮的城池：** 这里没有传统的 IP 扫描，取而代之的是对 IAM（身份和访问管理）角色的争夺。一个泄露的 `Access Key`，其破坏力丝毫不亚于内网的域管密码。
- **🚀 跨界打击：** 我们将探索如何通过元数据服务（Metadata）的 SSRF 漏洞窃取云凭证，如何利用云主机的角色权限，在不知不觉中接管整个云存储桶（S3/OSS），实现从“地面机房”到“云端核心”的跨界斩首。
