# 速查词典

## 💻 模块一：底层开发与恶意代码 (核心) {#模块一底层开发与恶意代码-核心}

本模块词汇主要围绕 Shellcode、Loader 以及相关编程语言。

| 中文术语 | 英文术语 | 定义与作用 | 在攻防中的用途 |
| --- | --- | --- | --- |
| **外壳代码** | Shellcode | 一串纯粹的机器指令，是让 CPU 执行特定任务的核心代码。 | 你的“**子弹**”，负责反弹 Shell 或建立 C2 连接。 |
| **加载器** | Loader | 你编写的程序，负责将 Shellcode 放入内存并启动执行。 | 你的“**枪**”，用于绕过杀软执行 Shellcode。 |
| **C++** | C++ | 一种性能极高、可直接操作内存的编程语言。 | **核心语言。** 用于编写 Loaders、Implant 等底层恶意代码。 |
| **Python** | Python | 一种高级脚本语言，开发效率高，语法简洁。 | **辅助语言。** 用于编写 C2 服务器、快速扫描脚本或数据处理。 |
| **Visual Studio** | VS | 微软提供的集成开发环境。 | 编译和调试 Loaders 等 C/C++ 项目的主要工具。 |
| **机器码** | Machine Code | CPU 能直接理解和执行的二进制指令。 | Shellcode 的原始形式。 |
| **免杀** | Evasion | 使恶意程序不被杀毒软件或安全产品检测到的技术。 | 攻击者必须绕过的主要防御。 |
| **混淆** | Obfuscation | 通过加密、变形、打乱代码等方式，隐藏恶意程序真实的逻辑或数据。 | 让杀软“**看不懂**”你在做什么。 |

## 🏢 模块二：企业内网与域安全（Active Directory） {#模块二企业内网与域安全active-directory}

本模块词汇是内网渗透，特别是针对 Windows 域环境的基石。

| 中文术语 | 英文术语 | 定义与作用 | 在攻防中的用途 |
| --- | --- | --- | --- |
| **活动目录** | Active Directory (AD) | 微软提供的一套目录服务，用于集中管理 Windows 域环境下的用户、计算机和资源。 | **内网核心。** 渗透测试中首要的攻击目标。 |
| **域控制器** | Domain Controller (DC) | 运行 AD 服务的服务器，负责验证用户身份、存储所有账户信息和策略。 | 掌握 DC 权限，即掌握了**整个内网**。 |
| **组策略对象** | Group Policy Object (GPO) | 一组配置规则，DC 用它来管理域内所有用户和计算机的行为和安全设置。 | 攻击者常利用 GPO 漏洞来执行代码或修改系统配置。 |
| **提权** | Privilege Escalation | 在目标系统上从低权限提升至更高权限（如管理员、System、域管理员）。 | 内网渗透的**关键步骤**。 |
| **持久化** | Persistence | 攻击者确保在系统重启或会话中断后，仍然能够重新连接和控制目标系统的技术。 | 稳固战利品。 |

## 🚀 模块三：渗透基础设施与工具（含网络测绘） {#模块三渗透基础设施与工具含网络测绘}

本模块词汇主要涉及攻防过程中使用的框架、扫描工具、网络侦察平台和实用工具。

| 中文术语 | 英文术语 | 定义与作用 | 类别 |
| --- | --- | --- | --- |
| **C2 框架** | Command & Control (C2) | 用于远程控制上线目标机的服务器和工具系统。 | **工具框架** |
| **Nmap** | Network Mapper | 著名的网络发现和安全审计工具，用于扫描主机、端口和识别服务。 | **网络扫描** |
| **Fscan** | Fscan | 一款内网综合扫描工具，常用于快速发现内网中的存活主机和弱口令。 | **内网扫描** |
| **Burp Suite** | Burp Suite | 一套用于测试 Web 应用程序安全性的集成平台，含代理、扫描器等。 | **Web 安全** |
| **Shodan / Fofa** | Shodan / Fofa | 网络空间资产测绘平台，用于搜索暴露在互联网上的设备和服务指纹信息。 | **网络测绘** |
| **Netcat** | Netcat (nc) | 一个极其灵活的网络工具，被称为“网络瑞士军刀”，常用于端口监听和数据传输。 | **通用工具** |
| **reGeorg / NPS** | reGeorg / NPS | 基于 Web 协议（如 HTTP(S)）或 Socks 协议的隧道工具。 | **内网穿透** |

## 🌐 模块四：网络基础与高级概念 {#模块四网络基础与高级概念}

本模块词汇涵盖通信、协议、系统底层和对抗分析。

| 中文术语 | 英文术语 | 定义与作用 | 安全背景 |
| --- | --- | --- | --- |
| **反向连接** | Reverse Connection | 由目标机器主动连接回攻击者服务器，用于绕过目标防火墙对入站流量的限制。 | C2 通信技术 |
| **SOCKS 协议** | SOCKS Protocol | 一种网络协议，用于在客户端和服务器之间建立代理连接，可代理任何流量。 | 内网穿透中建立**隧道**。 |
| **HTTPS** | HTTPS | HTTP 协议的安全版本，通过 **SSL/TLS** 协议进行加密通信。 | C2 通信中常用于伪装流量。 |
| **数字证书** | Digital Certificate | 用于验证服务器身份的电子文件，是 HTTPS 信任的基础。 | C2 基础设施部署（用于伪造 C2 证书） |
| **AV / EDR** | Antivirus / EDR | 杀毒软件 / 终端检测与响应系统，负责阻止恶意活动。 | 攻击者必须绕过的防御系统。 |
| **Windows 内核** | Windows Kernel | 操作系统最核心的部分，负责管理系统资源和硬件，拥有最高权限。 | 内核级提权是最高级别的目标。 |
| **VMware/VirtualBox** | VM | 在宿主机上模拟出的隔离计算机环境。 | 搭建靶场、运行恶意代码的**必备安全环境**。 |
