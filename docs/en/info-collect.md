# 信息收集 - 了解你的目标

## 1. 欢迎来到红队的世界 👋 {#h-1-欢迎来到红队的世界}

在电影里，黑客总是手指在键盘上飞舞，屏幕上绿色代码疯狂滚动，然后在 10 秒钟内攻破五角大楼。<br> 但在现实中，如果你这样做，只会发生一件事：**还没连上对方服务器，你就被拉黑了。**

真实的红队行动（Red Teaming），遵循 **“90% 的信息收集 + 10% 的漏洞利用”** 这一黄金法则。

### 什么是信息收集？ {#什么是信息收集}

简单来说，就是**合法的偷窥**。<br> 在真正发起攻击之前，我们利用互联网上公开的一切渠道，去搜集关于目标的所有情报。这个过程通常不需要写一行恶意代码，甚至不需要碰触目标的服务器。

我们利用的是**信息差** —— **你知道的关于目标的信息，比目标管理员以为你知道的要多。**

---

## 2. 我们到底在收集什么？ 🧩 {#h-2-我们到底在收集什么}

红队眼里的“目标”，不是一台冰冷的服务器，而是一个由**机器、人、代码**组成的复杂有机体。我们的收集工作主要分为三个维度：

### 🏛️ 第一维度：数字资产（机器） {#️-第一维度数字资产机器}

这是最直观的目标。

- 目标有多少个网站？
- 也就是我们下一章要讲的“资产测绘”。
- **通俗理解：** 就像你要去偷一家公司，你得先知道它有几个分公司？仓库在哪？有没有忘记关的后门？

### 👥 第二维度：人员情报（人） {#第二维度人员情报人}

系统是人维护的，代码是人写的，而**人是最大的安全漏洞**。

- **我们要找谁？** 管理员、运维人员、财务、HR。
- **去哪找？** LinkedIn（领英）、微博、社交媒体。
- **有什么用？**
    - 如果你知道管理员喜欢这就叫“旺财”的狗，他的密码会不会是 `Wangcai123`？
    - 如果你知道某个员工的邮箱，是不是可以发一封精准的“钓鱼邮件”？

### 🤐 第三维度：泄露的秘密（代码与密钥） {#第三维度泄露的秘密代码与密钥}

这是新手最容易忽略，但往往最致命的环节。现在的开发者很喜欢把代码传到云端，或者为了方便，把“钥匙”留在了锁眼里。

#### 1. 公开的代码仓库 (如 GitHub) {#h-1-公开的代码仓库-如-github}

很多程序员会把公司的代码上传到 GitHub 上。

- **严重后果：** 有时候，他们会不小心把**数据库密码**、**后台管理员账号**直接写在代码里传上去。
- **红队视角：** 我们不需要入侵服务器，我们只需要在 GitHub 上搜一下目标公司的名字，有时就能捡到“上帝的钥匙”。

#### 2. 前端 JS 中的 AK/SK (Access Key / Secret Key) {#h-2-前端-js-中的-aksk-access-key-secret-key}

- **这是什么？** 现在的网站经常使用阿里云、AWS 等云服务。为了操作这些服务，需要一种叫 AK/SK 的密钥（相当于云账号的账号密码）。
- **错误操作：** 有些粗心的开发人员，直接把这个密钥写在了浏览器加载的 JavaScript (JS) 文件里。
- **红队视角：** 右键 -> 查看网页源代码 -> 搜索 "Key"。如果找到了，恭喜你，你可能直接接管了对方的云端服务器，连密码都不用破。

## 3. 为什么要这么麻烦？直接干不行吗？ 🛑 {#h-3-为什么要这么麻烦直接干不行吗}

**不行。**

想象一下你是狙击手（红队） vs 机枪手（新手）：

- **机枪手（新手）：** 哪怕不知道敌人在哪，对着草丛一顿乱扫。
    - **结局：** 子弹打光了，也没打中人，反而暴露了自己的位置，被反杀。
- **狙击手（红队）：** 趴在草丛里观察了三天三夜（信息收集），确定了指挥官的位置，风速，距离。
    - **结局：** 扣动一次扳机，任务结束。悄无声息。

**充分的信息收集能让你：**

1. **避开防御：** 知道哪里有防火墙，哪里没有。
2. **节省时间：** 不用去试那些根本不存在的漏洞。
3. **一击必杀：** 找到那个最脆弱的点（比如一个泄露的密钥），瞬间获得权限。

## 4. 总结：像侦探一样思考 🧠 {#h-4-总结像侦探一样思考}

在这一阶段，请忘掉你是一个黑客，把你自已想象成一个**侦探**。

- 你的工具不是病毒或者漏洞，而是**搜索引擎**（Google, Baidu）。
- 你的战场不是黑色的终端窗口，而是**浏览器**。
