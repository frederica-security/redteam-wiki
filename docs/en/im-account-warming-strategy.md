# 储备消耗战 : 你的养号策略

为什么要打这场“储备消耗战”？

在上一章中，我们强调了 IM 消息相比邮件的巨大优势：**信任感高**、**易于挥发**（撤回后难以取证）以及**客户端攻击面广**。

然而，所有这些优势都依赖于一个前提：**你的 IM 账号能够存活**。

用于侦察、钓鱼和渗透的账号本质上是**消耗品**。每一次成功的钓鱼，都伴随着极高的被举报风险。尤其当你利用像微信这样的平台时，你正在挑战一套基于社交图谱、行为分析和大数据风控的复杂系统。

一旦你的账号被目标用户举报或触发平台风控：

1. **行动中断：** 账号立即被封禁，消息无法发送，你精心设计的攻击链条（OAuth 链接或 LNK 文件）瞬间失效。
2. **横向打击：** 平台会启动**横向检测机制**，扫描同 IP、同设备、同 WIFI 下的其他账号，导致你的整个账号池资源崩溃。

因此，红队的策略必须是一场**储备消耗战**——你需要持续、稳定地投入资源，通过**养号**来提高账号的**权重分**，以确保在战斗中能经受住举报，维持高自由度的操作空间。

## 微信风控：账号“权重”决定命运 {#微信风控账号权重决定命运}

微信的本质是一套**账号评分体系**。一个高权重的账号，即使进行与低权重账号相同的“钓鱼”操作，也可能安然无事。这是因为腾讯会将有限的监控资源优先倾斜给**低权重、高风险**的账号。

### 核心指标：你不能碰的数字红线 {#核心指标你不能碰的数字红线}

这些数字是普遍安全值，一旦触碰很容易立即触发风控。

| 限制类型 | 限制数值 | 风险说明 |
| --- | --- | --- |
| **主动添加好友** | 每天 ≤ 50 人；每 10 小时 ≤ 15 人 | 超出阀值，你发送的钓鱼请求对方无法收到，并有封号风险。 |
| **被动添加好友** | 每天 ≤ 200 人 | **钓鱼初期**，被动添加是安全拉客的方式。 |
| **建群/进群** | 每天进群 ≤ 10 个；群人数超 100 需实名验证。 | 批量进群是账号异常活跃的重要特征。 |
| **好友上限** | 总上限约 5000+ 人 | **注意：** 好友数超过 4000 人反而会降低权重分。 |

> **关键思路：** 风控的判断不仅看 **“全天指标”**，更看 **“单位时间指标”**。一次性加 20 人立即封号，分摊到每小时加 5 人，则可能安全达标。

### 权重加分规则：模拟真实用户 {#权重加分规则模拟真实用户}

你的养号策略，就是模拟一个**重度、多元化、高质量**的真实用户。

| 行为类别 | 操作目的与价值 |
| --- | --- |
| **基础信息** | **完整性满分**：绑定手机号、银行卡、QQ、邮箱，完成实名认证。 |
| **使用时长** | **注册时间越长，权重越高**。这是最难用技术弥补的指标。 |
| **聊天互动** | 图文、语音、视频等**互动方式多样**，与多个好友维持稳定、**双向**的聊天频率。 |
| **内容生态** | 经常发朋友圈，与好友有点赞和评论互动；阅读腾讯新闻、订阅和阅读公众号。 |
| **金融行为** | 经常使用微信支付、发/抢红包、购买理财产品、充值话费。**这是证明账号价值最高的行为。** |

### 权重扣分规则：避免“程序行为” {#权重扣分规则避免程序行为}

所有**中间没有其他操作、单一行为频繁重复**的动作，都会被判定为机器操作，导致扣分。

| 扣分风险点 | 描述 |
| --- | --- |
| **环境异常** | 使用黑名单 IP；同一 WiFi 下大量账号进行相同操作；IP 或定位发生突变。 |
| **行为异常** | 个人信息改动过于频繁；新加好友不互动，且被删除比例过高。 |
| **单一高频** | 短时间发 10 条以上朋友圈；频繁刷新“附近的人”或摇一摇（高风险功能）。 |
| **违规内容** | 发送包含欺诈、色情、政治、金融敏感词汇（如发票、期货、支付宝、银行账号）的信息。 |

## 账号注册与存活：基地的建立 {#账号注册与存活基地的建立}

新号的存活周期是所有策略的基石。在注册阶段，平台会进行最严格的设备和环境检测。

### 注册的原则（环境控制） {#注册的原则环境控制}

1. **设备限制：** 一台手机**一个月注册次数 < 5 次**，一天 < 2 次。
2. **IP 切换：** 注册时必须使用**手机流量卡**，在第二次注册前，必须启动**两次飞行模式**（强制切换 IP）。
3. **环境固化：** 注册完成后**不能立即切换手机登陆**，尽量在原手机保持 **7 天**以上。
4. **批量规避：** 即使购买账号，也要选择**传统号段 (13x)**，且手机号码**不要挨着**。
5. **安卓优先：** **安卓系统**注册的账号，因其系统权限和可收集的信息更多，权重通常高于苹果系统。

## 极简养号术：打造“老号”的日常 {#极简养号术打造老号的日常}

养号有两个目的：**提高权重防封**，以及**铺垫朋友圈提高信任度**（为你的**钓鱼话术**提供背景支撑）。

### 新号上线：首周核心操作（高风险期） {#新号上线首周核心操作高风险期}

这是新号适应环境、获得信任的阶段，必须谨慎。

| 时间 | 操作重点 | 注意事项 |
| --- | --- | --- |
| **第一天** | 互加 3-5 个老号；老号给新号备注/标签；互聊 5-10 句话。 | **不要立即修改全套资料！** 让账号适应环境。 |
| **次日** | 设置微信号（不能有规律）；模拟对话；发一条朋友圈。 | 资料修改不要批量、不要有规律，且要错开时间。 |
| **持续 7 天** | **保持手机流量**；打开定位（模拟移动轨迹）；每天至少发送一次朋友圈。 | 资料设置好后一段时间内不要频繁修改。 |

### 高权重日常维护：多元互动 {#高权重日常维护多元互动}

目标是**多元化、日常化**的使用，避免任何单一的高频动作。

1. **聊天互动：**
    - 与 3-5 个好友聊天，每天分三个时间段，每次 5-10 句**双向**对话（文字、语音、图片等多样内容）。
    - **战术价值：** 确保账号权重，以便后续发送 OAuth 链接或 LNK 文件时不被立即拦截。
2. **内容生态：**
    - 模拟阅读腾讯新闻、订阅公众号，并**分享到朋友圈**，用其他号点赞评论。
    - **战术价值：** 打造一个有血有肉的社交形象，为你的**钓鱼话术**提供可信背景。
    - 多刷视频号：这是微信的重点主推新功能，能显著的增加你的账号权重。
3. **金融与发现：**
    - 发 1 个红包给老号，收 1 个红包。
    - 模拟使用游戏、购物等功能。
    - **战术价值：** 增加账号的金融权重，提高在风控系统中的地位。

## 终极防御：平台的监控规则（知己知彼） {#终极防御平台的监控规则知己知彼}

了解微信的三大监控规则，才能理解你的每一次操作都在被如何评估，从而规避**程序化行为**。

1. **监控等级规则 (Level Monitoring)：**
    - 不同权重的账号对应不同的监控强度。资源有限，优先监控低权重账号。
2. **横向检测规则 (Horizontal Detection)：**
    - 当你的一个账号因钓鱼行为被判断异常后，腾讯会立即扫描**同 IP、同定位**下的其他账号是否有同样的异常，**同环境的账号会被牵连**。
3. **属性监控规则 (Attribute Monitoring)：**
    - 根据账号的性别、地区等属性进行功能限制。例如，某些功能只对特定属性的账号开放。

**总结：** 储备消耗战是一场对细节、耐心和环境控制的考验。你的目标是将你的“料号”培养成一个拥有最高自由度、足以承受几次用户举报的“惯犯”，以保障你在 IM 攻防链中的资源稳定。
