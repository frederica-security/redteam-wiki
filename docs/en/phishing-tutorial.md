# 钓鱼，你的第一台战利品

## 引言：从理论到实战的关键一跃 {#引言从理论到实战的关键一跃}

### 回顾：我们到底在做什么？ {#回顾我们到底在做什么}

在上一个大章节《木马 - 一切行动的基石》中，我们学会了：

- 如何生成 Beacon
- 如何上线并控制目标机器
- 如何致盲 EDR
- 如何清理痕迹

**但所有这些技术，都依赖于一个基本的事实：**

> 目标正在运行着我们的 `.exe` 文件

想象这个场景：

```text
你精心制作了一个 Beacon：
✅ 免杀处理完美
✅ 混淆了所有特征
✅ C2 基础设施完备
✅ 权限维持方案齐全

但是...

❌ 你无法让目标双击运行它
```

**这就像一把锁匠精心打磨的万能钥匙，却无法塞进锁孔。**

---

### 🎯 本章的核心问题 {#本章的核心问题}

**如何在对方的办公电脑上，执行我们的木马？**

这个问题有三个关键维度：

1. **投递方式：** 怎么把木马送到目标手里？
2. **伪装技术：** 怎么让木马看起来"无害"？
3. **心理战术：** 怎么让目标愿意打开它？

本章将严肃认真地面对这个问题，因为**没有第一台机器，就没有后续的一切。**

钓鱼的本质：一场精心设计的骗局

---

### 为什么钓鱼是红队的"必修课"？ {#为什么钓鱼是红队的必修课}

根据 Verizon 2023 数据泄露调查报告：

```text
超过 80% 的 APT 攻击使用钓鱼作为初始访问手段
精心设计的钓鱼成功率：15-30%
鱼叉攻击（针对高管和核心骨干）：40-50%
```

**原因很简单：**

- Web 服务器可以打补丁
- 防火墙可以配置规则
- 但**人性的弱点**无法修补
