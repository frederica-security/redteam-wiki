# 资产测绘 - 知道你在进攻什么

## 1. 引言：不要做那个“盲目踹门”的人 {#h-1-引言不要做那个盲目踹门的人}

很多新手拿到目标后的第一反应是：打开工具，对着主站一顿乱扫。<br> 🔴 **结果：** 3 秒后被防火墙（WAF）拉黑，连登录框都没见到，游戏结束。

**资产测绘（Asset Mapping）** 就是在攻击开始前，绘制一张目标的“全景地图”。你的目标不是去撞最硬的墙，而是找到那扇忘记上锁的窗。

---

## 2. 什么是“资产”？ (Your Targets) 🎯 {#h-2-什么是资产-your-targets}

在网络世界里，资产不仅仅是钱，而是**目标在互联网上拥有的所有“触点”**。只要是能通网的，都可能是突破口。

### 🏛️ 域名 (Domain) {#️-域名-domain}

就像房子的招牌（如 `example.com`）。

- **重点关注：子域名 (Subdomains)**
    - 主站 (`www`) 通常防御最严密。
    - 但开发服 (`dev`)、测试服 (`test`)、旧版系统 (`old`)、VPN 入口 (`vpn`) 往往是防御的**短板**。

### 🏠 IP 地址 (IP Address) {#ip-地址-ip-address}

就像房子的门牌号（如 `203.0.113.10`）。

- 有时候域名套了 CDN（内容分发网络，相当于保护罩），你打的是 CDN 节点而不是真实服务器。找到**真实 IP** 也是测绘的重要一环。

---

## 3. 必须要懂的网络基础：B 段与 C 段 🌐 {#h-3-必须要懂的网络基础b-段与-c-段}

新手经常听到老手说：“扫一下它的 C 段”。这是什么意思？

IP 地址通常长这样：`192.168.1.10` (A.B.C.D)。我们可以把它想象成行政区划：

- **C 段 (C-Class / /24)：**
    - 指 IP 的前三段相同，只有最后一段不同。
    - **例子：** 目标 IP 是 `1.1.1.10`，它的 C 段邻居是 `1.1.1.1` 到 `1.1.1.255`。
    - **红队视角：** 企业通常会买一整段连续的 IP。如果 `1.1.1.10` 是防御森严的主站，那么住在隔壁的 `1.1.1.11` 很可能就是一台**没有任何防护的测试服务器**。拿下邻居，就等于进入了内网小区。
- **B 段 (B-Class / /16)：**
    - 指 IP 的前两段相同（范围更大）。
    - 通常只有超大型互联网公司或集团才会拥有 B 段资产。扫描 B 段耗时较长，但能发现更多边缘资产。

---

## 4. DNS 解析：互联网的电话本 📖 {#h-4-dns-解析互联网的电话本}

- **概念：** 电脑记不住 `www.google.com` 这种单词，它只认识 IP。DNS 就是把“域名”翻译成“IP”的服务。
- **A 记录：** 域名对应的 IPv4 地址。
- **CNAME：** 域名的别名（常用于识别是否使用了 CDN）。
- **DNS域传送漏洞：** 由于dns配置不当，本来只有备份服务器能获得主服务器的数据，由于漏洞导致任意client都能通过“域传送”获得主服务器的数据。
- **红队技巧：** 查看 DNS 历史记录（Historical DNS）。有时现在的域名解析到了高防 IP，但半年前的历史记录可能暴露了它的**真实源站 IP**。

---

## 5. 指纹识别 (Fingerprinting)：这是什么材料做的？ 🔍 {#h-5-指纹识别-fingerprinting这是什么材料做的}

找到了房子（IP/域名），你还得知道这房子是用什么材料盖的。

- **Web 指纹：** 网站是用什么技术写的？
    - 如果你识别出目标用的是 **WordPress**，你就去搜 WordPress 的漏洞。
    - 如果你识别出目标用的是 **Java (Spring Boot)**，你就去测试 Java 反序列化漏洞。
- **端口指纹：** 只有 80/443 端口（网页）吗？
    - 开放了 **3389**？那是远程桌面，可以尝试爆破密码。
    - 开放了 **3306**？那是 MySQL 数据库，可能存在弱口令。

---

## 6. 高级侦察：通过“特征”寻找隐藏目标 🕵️‍♀️ {#h-6-高级侦察通过特征寻找隐藏目标-️️}

有些资产没有绑定明显的域名，或者藏在云服务器里，怎么找到它们？这时候要用“侧写”技术。

### 🖼️ Favicon Hash (图标哈希) {#️-favicon-hash-图标哈希}

**原理：** 每个网站浏览器标签页上的那个小图标（Favicon.ico），在代码里都是一串特定的二进制数据。我们可以计算这串数据的“指纹”（Hash 值）。<br> **实战：**

1. 计算目标主站图标的 Hash 值。
2. 在网络空间搜索引擎（如 Shodan/Fofa）里搜索这个 Hash。
3. **惊喜：** 你可能会发现几十个 IP 使用了完全相同的图标。这些 IP 即使没有绑定域名，也大概率是属于同一家公司的（比如后台管理系统、开发测试环境）。

### 📜 HTTPS 数字证书 (SSL Certificate) {#https-数字证书-ssl-certificate}

**原理：** 为了实现 HTTPS 加密，网站必须安装证书。证书里包含“颁发给谁”的信息（Organization 或 Common Name）。<br> **实战：**

1. 查看目标网站的证书信息，比如“颁发给：Jack Corp”。
2. 搜索所有证书中包含“Jack Corp”的 IP 地址。
3. **惊喜：** 你能找到所有属于该公司的服务器，哪怕它们仅仅是一个跑在 AWS 上、只有 IP 的测试接口。

## 7. 为什么要这么做？一个关于“封 IP”的教训 🚫 {#h-7-为什么要这么做一个关于封-ip的教训}

为什么新手总是还没开始就被封号，而老手却能从容进出？

### ❌ 新手剧本：正面硬刚 {#新手剧本正面硬刚}

1. 锁定目标主站 `www.target.com`。
2. 开启全端口扫描器，速度拉满。
3. **结局：** 目标的 WAF（Web 应用防火墙）检测到高频流量，判定为攻击，直接封禁你的 IP。你什么都没得到，还暴露了自己的意图。

### ✅ 高手剧本：寻找“软柿子” {#高手剧本寻找软柿子}

1. **资产测绘：** 通过子域名挖掘和证书查询，发现目标有一个新上线的业务 `beta-shop.target.com`，以及同 C 段的一个 `192.168.x.x` 的测试服务器。
2. **分析：** 这个新业务（New Biz）刚上线，为了调试方便，可能**关掉了防火墙**；而那个 C 段的 IP 可能是个旧系统（Legacy），没人维护。
3. **进攻：** 避开主站，直接攻击这个边缘的测试系统。
4. **结局：** 轻松拿到权限，并以此为跳板，从内部渗透进主站网络。

> 💡 **总结：** 资产测绘的核心目的，是避开防守最严密的正门，找到那个被管理员遗忘的、缺乏维护的、或者正在测试的**脆弱入口**。
