# 钓鱼导论 - 信任关系的建立和诱导

## 钓鱼话术：心理战的艺术 {#钓鱼话术心理战的艺术}

有了伪装技术，还需要话术配合。而话术是用来建立信任关系的，有了足够的信任关系，才可以驱使对方进行一些非常规行为。

### 💼 话术一：应聘/招聘（最泛用） {#话术一应聘招聘最泛用}

**为什么应聘招聘的模式很泛用？**

没有哪家公司不招人，除非它太小了，就算裁员期的公司也招人。<br> 没有哪家公司的员工不想跳槽，就算待遇很好，也难免有工作不顺心的时候。<br> 而且：

```text

1. HR 不是技术人员，安全意识相对薄弱
2. 简历有"分发属性"（HR 会转给用人部门）
3. 可以通过第三方平台建立信任
4. 应聘者可能面临裁员危机 急着找工作
```

**完整话术示例：**

```text
主题：应聘【前端开发工程师】- 张三 - 3年经验

您好，李经理：

我叫张三，毕业于XX大学，3年前端开发经验。
在 Boss 直聘上看到贵司在招聘前端工程师，非常感兴趣。

我的技术栈：
- Vue 3 / React 18
- TypeScript
- 微前端架构

附件是我的简历和作品集，麻烦查看。

期待您的回复！

张三
手机：138-0000-1234
微信：zhang_san_dev
```

**附件：**

- `张三-前端开发-3年.7z`（解压后包含**个人简历.pdf.lnk**）

### 💼 话术三：假漏洞应急 {#话术三假漏洞应急}

**场景：** 目标公司用了第三方软件，正好有漏洞

**话术示例：**

```text
主题：【严重漏洞】某某系统存在 SQL 注入

您好，安全团队：

我方是 XX 系统供应商，该系统最近存在 SQL 注入漏洞。

漏洞详情：
- URL: https://xxx.com/api/user
- 参数：id
- 影响：可以获取所有用户信息

附件是漏洞复现工具和截图，请尽快修复。

（附上几张看起来很专业的截图）
```

**附件：**

- `SQL注入复现工具.exe`（实际是木马，但会真的输出一些看似漏洞的数据）
- `漏洞截图.png`（真实的截图）

**为什么有效？**

- 利用应急人员的责任心
- 即使知道有风险，也不得不查看
- 如果是真漏洞，不处理会造成严重后果

### 💼 话术四：可信站点中转 {#话术四可信站点中转}

**问题：** 邮件网关会扫描附件

**解决：** 把木马传到目标公司自己的网站

**操作步骤：**

```text
1. 找到目标公司的某个可上传文件的地方
   - 论坛
   - 文件分享平台
   - 招聘系统

2. 上传你的木马
   获得下载链接：https://目标公司.com/files/简历.7z

3. 发送钓鱼邮件：
   "这是我的简历，已经传过一次你们的招聘系统了：https://目标公司.com/files/简历.7z"
```

**为什么有效？**

- 下载链接是目标公司自己的域名
- 邮件网关可能不会拦截自己域名的链接
- 用户看到是公司域名，更容易信任

### 💼 话术五：第三方平台引流 {#话术五第三方平台引流}

**场景：** 通过招聘网站建立信任

**操作流程：**

```text
1. 在 Boss 直聘上找到目标公司的招聘信息
2. 投递简历（正常的简历，不含木马）
3. 和 HR 聊天，建立信任
4. HR："能发一下你的详细简历吗？"
5. 你："好的，我用邮件发给您"
6. 发送钓鱼邮件（此时 HR 已经信任你）
```

## 电话沟通：国内特色的"钓鱼加速器" {#电话沟通国内特色的钓鱼加速器}

### 📞 为什么电话沟通在国内特别有效？ {#为什么电话沟通在国内特别有效}

**国内的特殊文化背景：**

```text
1. 中国人重视"人情"，电话沟通后更容易信任
2. 很多企业员工习惯电话确认邮件内容
3. 语音比文字更容易建立信任感
4. 可以实时引导，解决对方的疑虑
```

**数据对比：**

```text
仅发邮件的成功率：10-15%
邮件 + 电话的成功率：30-40%
```

---

### 📞 电话沟通的三个时机 {#电话沟通的三个时机}

#### 时机一：发送邮件前 {#时机一发送邮件前}

**场景：** 伪装成求职者

```text
对话示例：

你："您好，是李经理吗？我在 Boss 上看到贵司在招前端开发。"
HR："是的，你是？"
你："我叫张三，有 3 年经验，想应聘这个职位。"
HR："好的，你把简历发到 hr@xxx.com"
你："好的，我马上发，麻烦您查收。"

（挂断电话后立即发送钓鱼邮件）
```

**为什么有效？**

- ✅ 建立了真实的联系
- ✅ HR 会主动去找你的邮件
- ✅ 有了电话沟通，HR 不会怀疑邮件的真实性

---

#### 时机二：发送邮件后（最常用） {#时机二发送邮件后最常用}

**场景：** 对方可能在手机上查看邮件

```text
等待 10-15 分钟后打电话：

你："您好，李经理，我是刚才给您投简历的张三。"
HR："哦，我看到邮件了。"
你："麻烦您查收一下，如果有任何问题可以随时联系我。"
HR："好的，我看看。"

（如果对方在手机上）
HR："诶，我在手机上打不开你的简历。"
你："哦，不好意思，我这个简历是用 Word 编辑的，用手机可能打不开。您方便的话，在电脑上用 Word 打开一下就可以了。"
```

**关键话术：**

```text
"这个文件是在电脑上编辑的，需要用 Word/Excel 打开"
"手机上可能显示不正常，建议在电脑上查看"
"我的作品集里有一些交互效果，手机上看不了"
```

---

#### 时机三：对方犹豫时 {#时机三对方犹豫时}

**场景：** 对方可能产生了怀疑

```text
如果对方长时间没有反应，再次打电话：

你："您好，李经理，我想确认一下您是否收到了我的简历？"
HR："收到了，不过我还没打开。"
你："好的，没关系。我看贵司这个职位要求有 Vue 和 React 经验，正好是我擅长的，所以特别想争取这个机会。您方便的话帮我看一下吧。"
HR："好的，我待会看看。"

（施加一点点压力，同时表达真诚）
```

### 📞 电话沟通的进阶话术 {#电话沟通的进阶话术}

#### 话术一：制造紧迫感 {#话术一制造紧迫感}

```text
"李经理，我这边还有另外两个 offer 在等我回复，但我还是更想加入贵司。如果您觉得合适的话，咱们能尽快安排个面试吗？"

（暗示：我很抢手，你要抓紧）
```

---

#### 话术二：建立专业形象 {#话术二建立专业形象}

```text
"李经理，我看到贵司用的是 Vue 3 技术栈，我之前在 XX 公司也是做这个的，还做过一些性能优化的工作。我的简历里有详细的项目经验，您可以看一下。"

（用专业术语增加可信度）
```

---

#### 话术三：应对"手机打不开" {#话术三应对手机打不开}

```text
对方："我在手机上打不开你的简历。"

你的回应（选择一种）：

方案一（推荐）：
"不好意思，我这个简历是用 Word 2019 编辑的，有些格式手机上显示不了。您方便的话，在电脑上用 Office 打开一下就好了。"

方案二（如果对方坚持）：
"要不这样，我重新保存一个 PDF 版本发给您？不过我的作品集链接在 Word 文档里，PDF 可能点不了。"

方案三（高级）：
"我看您是在手机上，要不等您回到办公室再看？我不着急，您方便的时候看就行。"
```

---

#### 话术四：应对"杀毒软件警告" {#话术四应对杀毒软件警告}

```text
对方："我打开的时候电脑提示有风险。"

你的回应：

镇定自若：
"哦，可能是因为我的简历里嵌入了一些作品集的链接，有些杀软会误报。您可以放心打开，我给很多公司都发过这个简历，都没问题的。"

或者：
"可能是您公司的安全软件比较严格，我的简历确实有一些超链接。要不您先放到白名单里，看完再删除也可以。"

（关键：语气要自然，就像在说一件很正常的事）
```

### 📞 电话沟通的黄金时间 {#电话沟通的黄金时间}

| 时间段 | 适合场景 | 原因 |
| --- | --- | --- |
| **10:00-11:30** | 初次联系 | 上午精神好，更容易沟通 |
| **14:00-15:00** | 跟进邮件 | 午休后，处理邮件的高峰期 |
| **16:00-17:00** | 催促打开 | 快下班了，想快速处理完 |

**避免的时间：**

- 9:00 之前（可能还没到公司）
- 12:00-14:00（午休时间）
- 18:00 之后（下班了，打私人电话会引起警觉）

### 📞 多次沟通策略 {#多次沟通策略}

**不要一次就放弃，可以分多次联系：**

```text
第 1 次（发邮件前）：
"您好，我想应聘贵司的职位，可以发个简历给您吗？"

第 2 次（发邮件后 15 分钟）：
"李经理，我刚才把简历发到您邮箱了，麻烦查收。"

第 3 次（如果还没打开，第二天上午）：
"李经理，不好意思打扰您，想确认一下您是否收到了我的简历？"

第 4 次（最后一次，下午时分）：
"李经理，我看还有几个公司在等我回复，但我还是最想加入贵司。如果您觉得我的经验不合适，也请告诉我一声，我好去考虑其他机会。"

（最后一次带一点点"威胁"，但语气要委婉）
```

## 诱导话术：让目标按你的意图行动 {#诱导话术让目标按你的意图行动}

### 🎭 核心原则：引导而非命令 {#核心原则引导而非命令}

**错误示例：**

```text
"你必须在电脑上打开"
"你要用 Word 打开才行"
```

**正确示例：**

```text
"建议您在电脑上查看，手机上可能格式不对"
"用 Word 打开效果最好，我做了一些排版"
```

---

### 🎭 场景一：引导用电脑而非手机 {#场景一引导用电脑而非手机}

**对方：** "我在手机上看一下"

**你的回应：**

```text
选项 1（强调内容）：
"我的简历里有一些作品集的演示视频链接，手机上看可能加载比较慢。建议您在电脑上看，体验会好很多。"

选项 2（强调格式）：
"我用 Word 做了一些排版设计，手机上可能显示不太正常。您方便的话，在电脑上用 Office 打开一下吧。"

选项 3（制造紧迫感）：
"其实手机也能看，不过我的作品集链接可能点不了。要不您先大概看看，等回办公室了再仔细看？"
```

---

### 🎭 场景二：引导关闭杀毒软件 {#场景二引导关闭杀毒软件}

**对方：** "电脑提示这个文件有风险"

**你的回应：**

```text
选项 1（正常化）：
"可能是因为我的简历里嵌入了一些在线作品集的链接，有些安全软件会误报外部链接。您可以选择'仍要运行'就好了。"

选项 2（从众心理）：
"我给很多公司都发过这个简历，有些公司的安全软件确实会提示。不过您放心，我只是个求职者，不可能做什么奇怪的事情。"

选项 3（转移责任）：
"哦，您公司的安全策略比较严格啊。要不您先保存到桌面，然后加到信任列表里再打开？我之前有个朋友的公司也是这样。"
```

---

### 🎭 场景三：引导启用宏 {#场景三引导启用宏}

**对方：** "打开了，但是显示需要启用宏"

**你的回应：**

```text
选项 1（技术流）：
"哦对，因为我的简历里有一些自动生成的图表（如技能评分雷达图），需要启用宏才能正常显示。您点一下上面的'启用内容'就可以了。"

选项 2（正常化）：
"是的，我用了 Word 的一些高级功能，需要启用宏。这是正常的，很多专业简历模板都会用到。"

选项 3（暗示专业性）：
"对，我的简历用了一些动态展示效果，需要启用宏。您点一下'启用内容'，就能看到我的技能图表了。"
```

---

### 🎭 场景四：应对长时间不打开 {#场景四应对长时间不打开}

**对方没反应，你再次联系：**

```text
话术 1（关心式）：
"李经理，我担心您可能太忙了没看到邮件，所以再提醒您一下。如果您觉得不合适，也请告诉我一声，我好安排其他面试。"

话术 2（催促式）：
"李经理，我这边另一个公司要求明天给答复，但我还是更想加入贵司。您能帮我看一下简历吗？"

话术 3（专业式）：
"李经理，我仔细看了贵司的职位要求，我的经验应该是比较匹配的。如果您方便的话，能否安排个电话聊聊？我可以详细介绍一下我的项目经验。"
```

---

### 🎭 场景五：应对技术人员审查 {#场景五应对技术人员审查}

**对方：** "我们让技术部门先看一下你的简历"

**你的回应：**

```text
选项 1（表示理解）：
"好的，没问题。不过技术部门可能更关注我的代码能力，要不我直接把 GitHub 地址发给您？简历主要是给 HR 看的。"

选项 2（转移注意力）：
"当然可以。不过我的简历主要是介绍项目经验，技术细节在我的作品集网站上。要不我把链接也发给您？"

选项 3（如果已经暴露，及时止损）：
"好的，那我重新整理一下，发一个纯文本版本的简历给您。"
```

## Plan B：当办公台式机失手时的"夜间作战" {#plan-b当办公台式机失手时的夜间作战}

### 🌙 为什么要等到晚上？ {#为什么要等到晚上}

**场景：**

```text
你给目标公司的 HR 发了简历
等了一整天，Beacon 没有上线
查看邮件回执：邮件被打开了
但是没有机器上线

可能的原因：
1. 办公台式机有严格的 EDR
2. 网络出口有严格的防火墙策略
3. 目标在虚拟机/沙箱中打开了文件
4. 木马被杀软拦截了
```

**这时候，不要放弃。等到晚上，目标可能会：**

---

### 💻 两用机：你的"第二战场" {#两用机你的第二战场}

**什么是两用机？**

```text
笔记本电脑，既是办公设备，也是个人娱乐设备

员工白天在公司办公：
→ 连接公司有线网络
→ 受到严格的安全策略管控
→ 有 EDR、防火墙、网络监控

员工晚上带回家：
→ 连接家里的 WiFi
→ 可能还会 VPN 回公司内网
→ 安全策略松懈很多
```

---

### 🎯 两用机的三大特点 {#两用机的三大特点}

#### 特点一：安全措施相对松懈 {#特点一安全措施相对松懈}

```text
办公台式机：
✅ 强制安装 EDR
✅ USB 端口禁用
✅ 应用白名单
✅ 网络严格管控

两用机（笔记本）：
❌ 可能没装 EDR（影响性能，员工会抱怨）
❌ 可能只装了轻量级杀软
❌ 网络策略相对宽松（需要远程办公）
❌ 可能有本地管理员权限
```

**原因：**

- 笔记本需要在家办公，不能管控太死
- 员工经常抱怨 EDR 影响性能，IT 部门可能妥协
- 管理笔记本比管理台式机困难得多

---

#### 特点二：网络环境特殊 {#特点二网络环境特殊}

```text
情况 1：在家连接家庭 WiFi
→ 完全没有公司的网络安全设备
→ 木马可以自由出网
→ 但此时无法访问公司内网

情况 2：在家连接 VPN
→ 既可以出网（通过家庭网络）
→ 又可以访问内网（通过 VPN）
→ 这是最理想的情况！

情况 3：在咖啡厅/高铁上连热点
→ 如果目标公司内网不出网
→ 员工可能会用手机热点让电脑出网
→ 然后通过 VPN 访问内网
```

---

#### 特点三：时间窗口可预测 {#特点三时间窗口可预测}

```text
晚上 19:00 - 23:00：
- 员工回家后可能继续工作
- 或者打游戏、看视频（两用机的典型用途）
```

### 🤔 为什么两用机是"软肋"？ {#为什么两用机是软肋}

**从管理角度：**

```text
台式机：
→ 放在公司，IT 部门完全控制
→ 可以强制安装各种安全软件
→ 员工无法拆卸/修改

笔记本：
→ 员工带回家，IT 部门难以管控
→ 安装太多安全软件，员工会抱怨卡顿
→ 员工可能自己"优化"（卸载安全软件）
```

**从技术角度：**

```text
台式机：
→ 有线网络，稳定可控
→ 统一的网络策略
→ 统一的安全基线

笔记本：
→ WiFi 连接，环境多变
→ 家庭网络、公共网络、热点
→ 难以统一管控
```

**从心理角度：**

```text
在公司：
→ 警惕性高
→ 有安全意识培训
→ 有同事的"监督"

在家：
→ 警惕性低
→ "这是我自己的电脑"（虽然是公司的）
→ "反正在家，没人看见"
```

#### 方法二：像素跟踪（更隐蔽） {#方法二像素跟踪更隐蔽}

注意：在coremail环境（以及国内最常见的163、qq邮箱）中，这反而会容易导致被标记为垃圾邮件。

**原理：**

```text
在邮件正文中插入一个 1x1 像素的透明图片
图片地址：http://你的服务器/track/user123.png

用户打开邮件时：
→ 邮件客户端加载图片
→ 向你的服务器发送请求
→ 你知道了邮件被打开

服务器日志：
192.168.1.100 - [15/Jan/2024:14:23:15] "GET /track/user123.png"
```

**实现：**

```html
<!-- 在邮件 HTML 中插入 -->
<img src="http://你的服务器/track/user123.png" width="1" height="1" style="display:none">
```

**优势：**

- 用户完全无感知
- 不需要用户同意
- 成功率接近 100%（如果邮件客户端加载图片）

**问题：**

- 有些邮件客户端默认不加载外部图片
- Gmail 会通过代理加载图片（无法获取真实 IP）

---

#### 方法三：链接跟踪 {#方法三链接跟踪}

**原理：**

```text
在邮件中放一个下载链接
链接带有唯一标识符

示例：
"您好，这是我的简历：
 下载链接：http://你的服务器/resume/download?id=user123"

用户点击链接：
→ 服务器记录访问
→ 302 重定向到真实文件
→ 你知道了谁在什么时间点击了链接
```

**服务器端代码示例（Python Flask）：**

```python
@app.route('/resume/download')
def download():
    user_id = request.args.get('id')
    ip = request.remote_addr
    user_agent = request.headers.get('User-Agent')

    # 记录访问日志
    log_access(user_id, ip, user_agent)

    # 重定向到真实文件
    return redirect('https://cdn.example.com/real-resume.pdf')
```
